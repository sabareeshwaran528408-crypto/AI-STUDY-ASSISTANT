1. Definition of a Distributed System

A Distributed System is an autonomous collection of physically separated computational nodes connected via a high-speed communication network. To the end-user and external applications, the entire aggregation presents itself as a single, coherent, unified computing facility (Tanenbaum & Steen Model).

2. Core Architectural Goals (Anna University / Exam Standard)
visibility_off A. Distribution Transparency

Hides the separation of resources: Location, Access, Migration, Replication, Concurrency, and Failure transparency.

lock_open B. Openness & Interoperability

Standardized interfaces using IDL (Interface Definition Languages) allowing independent subsystems to collaborate seamlessly.

trending_up C. Scalability Metrics

Horizontal scalability across 3 dimensions: Size (adding users), Geographical scale, and Administrative domain flexibility.

shield D. Fault Tolerance & Recovery

Partial failure containment without global shutdown via heartbeat protocols, checkpointing, and Byzantine consensus mechanisms.
